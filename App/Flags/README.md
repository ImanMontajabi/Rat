# Flags

Flat country flags (4:3 SVG) from [flag-icons](https://github.com/lipis/flag-icons) 7.2.3 by Panayiotis Lipiridis,
MIT licence (`LICENSE` here). Fetched from the npm registry (`flag-icons-7.2.3.tgz`, integrity checked against the
registry's sha512); the SVGs have no scripts or external references. `Flags.swift` frames them in Rat's style
(rounded corners, a bold outline, darker right and bottom edges, a faint sheen) and caches each size.
